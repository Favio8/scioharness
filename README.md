# ScioHarness

**一站式科研工作台，长期目标是全自动科研。**
A one-stop research workspace, aiming at fully automated research.

> 占位仓库：名字已经定了，代码还没开始。

## 名字

`scio`（拉丁语 *I know*）＋ `harness`（驱动模型的运行时）＝ 驱动科研的运行时。

## 将来是什么

ScioHarness 是 ScholarFlow 的独立 App 形态：

- **一站式**：文献检索 → 选题 → 大纲 → 写作 → 格式与导出，在同一条流水线上完成
- **全自动**：能委托的环节交给 agent 长时运行，人只在关键节点做判断
- 与 DSH 插件形态 [`dsh-scholarflow`](https://github.com/Favio8/dsh-scholarflow) 共用一套产品基线，能力边界待明确
